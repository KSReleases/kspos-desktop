# Buxopos Desktop — releases

Este repositorio solo publica los instaladores de la caja (Buxopos Desktop) y el `latest.json`
que consulta el actualizador automático. El código fuente no está aquí.

- Descarga: la sección **Releases**, último release estable.
- Actualizador: `https://github.com/KSReleases/kspos-desktop/releases/latest/download/latest.json`
- Cada instalador va firmado (archivo `.sig`); la caja rechaza cualquier paquete cuya firma no
  coincida con su clave pública.

No se aceptan issues ni pull requests en este repositorio.
